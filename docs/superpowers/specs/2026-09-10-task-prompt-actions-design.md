# 任务中心：用户提问操作

## 目标

在任务中心每个用户提问的蓝色气泡上，提供复制、修改和重新发送操作，方便运营人员复用已有问法。

## 范围与约束

- 仅作用于用户提问气泡，不改变机器人回复气泡已有操作。
- 不修改历史任务或其审计记录。
- 不新增后端接口，也不改变 Task Service 的任务状态逻辑。
- 仅在鼠标悬停用户气泡时显示操作条，保持任务列表紧凑。

## 交互设计

### 复制提问

复制该任务的原始 `input` 文本。剪贴板不可用时使用页面现有的降级复制方式，并在状态提示区显示成功提示。

### 修改

将原始 `input` 文本填入底部任务输入框，聚焦输入框并根据现有逻辑调整输入框高度。用户自行修改后点击发送；不设置 `replyTo`，不附加 `@#任务号`。

### 重新发送

直接使用原始 `input` 调用当前正常的 `POST /api/task` 提交链路，使用页面当前选中的防火墙。请求不携带 `replyTo`，因此是新的原始请求而非追问或任务克隆。服务端会按既有行为生成新的任务记录。

## 代码边界

- `webui/index.html`：在用户气泡渲染中增加悬停操作条和三个前端操作函数。
- 不修改 API Router、Task Service、任务持久化格式或机器人回复动作。

## 验收标准

1. 每个用户提问气泡包含复制、修改、重新发送三个可发现的悬停操作。
2. 复制内容仅包含原始提问。
3. 修改只回填输入框，不自动发送，不带回复关联。
4. 重新发送只提交原始提问与当前防火墙，不携带 `replyTo`。
5. 既有机器人回复操作和全量测试保持通过。
