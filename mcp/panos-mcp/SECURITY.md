## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Use one of these channels:

- **GitHub Private Vulnerability Reporting** (preferred) — click the "Report a vulnerability" button on the [Security tab](https://github.com/apius-tech/Palo-MCP/security/advisories/new).
- **Email** — michal.sienski@apius.pl

Include: affected version, description, reproduction steps, and potential impact. We aim to respond within 48 hours and to release a fix within 7 days for critical issues.
